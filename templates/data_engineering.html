Phase 3: Data Engineering

Transformations, Feature Engineering, and ML Preparation.

🧹

1. Data Cleaning

The raw CSV data was imported using Pandas. We implemented dynamic delimiter detection (handling both , and ; separators) and managed European decimal formats (, to .) to prevent data type errors.

  • Missing values check (Imputation if necessary).
  • Data type casting to `float64`.
  • Removal of duplicate records.
⚙️

2. Feature Engineering

To help our models understand the actual progress of the user, derived features were conceptually evaluated. The relationship between screen_time_pre and screen_time_post naturally models a "Reduction Rate".

Since our algorithms (especially Trees) handle non-linear relationships well, we kept the raw granular metrics (interactions, trivias, rewards) as direct features.

✂️
